#Zain National Bank System
A console-based banking system built in C#
##Features
Account creation with initial deposit
Login system
Deposite /Withdraw /Transfer
ATM Simulation
Interest calculation(Saving accounts)
Loan system
Admin panel
JSON data storage
##Technologies Used
C#
.NET
JSON File Handling
##How to Run
1.Open in Visual Studio
2.Run the program
3.Follow on-screen menu
